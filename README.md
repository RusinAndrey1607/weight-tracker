# Weight Tracker

Минималистичное PWA для личного трекинга веса. Стек: React, TypeScript, Vite, Firebase.

## Разработка

```bash
cp .env.example .env
npm install
npm run dev
```

Firebase подключается на следующих этапах. Сейчас приложение работает на mock-данных.

## Скрипты

- `npm run dev` — локальный сервер
- `npm run build` — production build
- `npm run lint` — ESLint
